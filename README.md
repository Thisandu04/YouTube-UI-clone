🎥 YouTube UI Clone (HTML & CSS)

📌 Project Overview

This project is a **YouTube homepage UI clone** built using **pure HTML and CSS**.
It replicates the layout and design of YouTube’s interface, focusing on structure, styling, and responsiveness.

🚀 Features

* 📺 YouTube-like video grid layout
* 🔍 Search bar with icons
* 📌 Sidebar navigation menu
* 🎯 Header with interactive icons (search, notifications, profile)
* 🖼️ Video thumbnails with titles, views, and channel info
* 💡 Clean and modern UI design

🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Roboto)

📂 Project Structure

│── Clone-Styles/

* Learned how to build **real-world UI designs**
* Enhanced skills in **responsive design**
